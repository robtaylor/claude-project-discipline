# Prose style

The layout keeps claims in the right place. A house prose style keeps them readable once they're there. Two readers matter: a contributor skimming for the answer, and a model that retrieves one section and repeats what it says. Both are served by the same rules. Put the point first, write in specific terms, and make sure every present-tense sentence is true of the code.

The starter kit ships the style below as [`starter/docs/prose-style.md`](https://github.com/robtaylor/claude-project-discipline/blob/main/starter/docs/prose-style.md). Copy it, adjust it to taste, and point `CLAUDE.md` at it so Claude reads it before writing docs. The CLAUDE.md snippet already does that.
